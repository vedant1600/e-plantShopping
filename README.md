# Paradise Nursery Shopping Application

Paradise Nursery is a React + Redux shopping cart application for an online plant shop.

## Features

- Paradise Nursery landing page with company name and Get Started button
- About Us page
- Product listing page
- 18 houseplants in 3 categories
- Product thumbnail, name, and price
- Add to Cart functionality
- Add button becomes disabled after adding a product
- Dynamic cart item count
- Increase/decrease quantity
- Delete items from cart
- Total quantity and total cost calculation
- Checkout button showing "Coming Soon"
- Continue Shopping button
- Responsive layout

## Technologies

- React
- React Router
- Redux Toolkit
- React Redux
- Vite

## Run the project

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite in the terminal.
